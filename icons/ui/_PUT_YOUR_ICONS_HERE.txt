Drop your own icon files in THIS folder, named exactly as below (lowercase),
e.g.  mountain.svg  backpack.svg  ...  (or .png if you set ICON_EXT='png' in app.js)

Then open app.js and change:   const USE_CUSTOM_ICONS = false;   ->  true

Tips:
- Use simple SINGLE-COLOUR icons on a TRANSPARENT background.
- The app auto-tints them (white on dark areas, blue on white buttons), so the
  colour of your file doesn't matter — only its shape.
- 24x24 SVG line icons look best. Square canvas recommended.
