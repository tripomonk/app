ILLUSTRATIONS
=============
The app shows friendly vector illustrations in empty states (e.g. "No bookings yet").

Current file:
  hiker-mountains.svg   — used on empty Bookings + empty region results

To use YOUR OWN illustration:
  1. Replace hiker-mountains.svg with your file (keep the SAME name), OR add a new
     file and update the <img src="illustrations/..."> references in app.js
     (search for "illustrations/").
  2. SVG or PNG both work. Transparent background, roughly 320x210, looks best on
     the dark app background.

Note on the painterly hiker you shared: that artwork is copyrighted by its artist,
so it can't be embedded as-is. If you license it (or commission similar art),
drop the file here and we'll wire it in.
